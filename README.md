# GENO / Peec AI 交互原型（标注版）

当前版本包含 46 条可编辑标注，覆盖提示词摘要、图表、排名、来源和聊天记录。顶栏和侧边栏不添加标注；当前版本移除了品牌选择和 All filters 两个界面控件，相关标注记录仍保留在目录中。

页面保留青绿色主题和原型交互，包括图表切换、筛选、排序、分页、详情弹窗及本地数据导出。

- `index.html`：可直接打开的完整页面，字体、图标与脚本已内嵌。
- `annotations.md`：46 条标注清单。

这是根据保存页面制作的交互原型，使用静态样例数据，未接入 Peec 账号或实时服务。
标注修改保存在查看者自己的浏览器中，不会同步给其他查看者或修改线上页面。

本仓库通过 GitHub Pages 从默认分支根目录发布。




外壳修复版 v7：GENO 顶栏和侧边栏正常渲染，品牌选择和 All filters 控件已移除。


Query fanouts 与 Common terms 暂不实现，相关查询入口及六条标注已移除。Question Metrics 侧栏入口暂显示未开放说明，其他区块继续可用。

来源分析：All domains／Expand 打开宽版分析。平台选择联动来源分布、明细与 CSV，域名列表默认折叠，详情返回保留筛选。全平台前八个域名覆盖 312／841 次引用；按平台分析仅统计已保存聊天中的已命名来源，缺失平台展示无数据。来源类型分布保持保存页的全平台统计。
